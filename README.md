# 划船 vs 飛輪 即時排行榜

輔仁大學 × 健身工廠 校園挑戰賽（11/17）用的即時排行榜。

| 檔案 | 用途 |
|---|---|
| `index.html` | **公開排行榜**：以手機瀏覽為主（也支援現場大螢幕），可搜尋暱稱找名次。只顯示暱稱、系級、機器、成績 |
| `submit.html` | **參賽者自行登錄**：填暱稱、系級（選填）、成績，加上本名、手機、電子錶照片 |
| `staff.html` | **管理頁（工作人員）**：輸入通行碼後核對照片、隱藏不實成績 |
| `config.js` | 設定檔：貼上 Apps Script 網址 |
| `Code.gs` | 後端程式，貼到 Google Apps Script（不要上傳到 GitHub 也可以） |

資料存在你自己的 **Google 試算表**，照片存在你的 **Google 雲端硬碟**，都只有你看得到。
活動結束後直接開試算表，就能看到第一名的本名和電話寄獎品。

---

## 一、建立後端（約 10 分鐘）

1. 開一份新的 Google 試算表，命名例如「校園挑戰賽成績」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把 `Code.gs` 全部內容貼進去，取代原本的程式碼，按儲存。
4. 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**
   - 屬性：`STAFF_CODE`
   - 值：自訂管理頁通行碼（例如 `ff1117`，只告訴工作人員；參賽者登錄不需要）
5. 右上 **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
   - 按部署，第一次會要求授權（試算表＋雲端硬碟），選自己的帳號 → 進階 → 前往（不安全）→ 允許
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

> 之後若修改 `Code.gs`，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 才會生效，網址不變。

## 二、設定網址

打開 `config.js`，把網址貼到 `API_URL`：

```js
API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

沒貼網址時，排行榜會顯示「範例資料」，方便先看版面。

## 三、上傳到 GitHub Pages

1. 到 GitHub 建立新的 repository（例如 `fju-ff-leaderboard`，設為 Public）。
2. 上傳 `index.html`、`submit.html`、`staff.html`、`config.js`（可以直接在網頁上拖曳上傳）。
3. repository 的 **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 `main` / `(root)`，儲存。
4. 約 1 分鐘後網址會出現：
   - 排行榜：`https://你的帳號.github.io/fju-ff-leaderboard/`
   - 參賽者登錄：`https://你的帳號.github.io/fju-ff-leaderboard/submit.html`（排行榜下方也有按鈕）
   - 管理頁：`https://你的帳號.github.io/fju-ff-leaderboard/staff.html`
5. 把排行榜網址做成 QR code，放到總覽板上的 QR code 位置。

## 四、活動當天

- **參賽者**：挑戰完 → 拍電子錶 → 掃 QR code 開排行榜 → 按「登錄我的成績」自己填 → 送出後馬上上榜。
- **工作人員**：手機開 `staff.html` 輸入通行碼，看最新登錄與照片，成績不符就按 **隱藏**（每 15 秒自動更新）。
- **大螢幕**：開排行榜網址，按 F11 全螢幕。
- **防呆**：划船機超過 250M、飛輪超過 700M 會被擋下；同一支手機最多登錄 10 次；排行榜只顯示每人最佳成績。
- **頒獎前**：到試算表把前幾名的照片都點開核對一次，再聯絡寄獎。

## 五、隱私

- 公開排行榜的資料 **只有暱稱、系級、機器、公尺數**，本名、手機、照片不會傳到前台。
- 管理頁沒有通行碼無法讀取任何資料；登錄頁只能新增成績，看不到別人的資料。
- 活動結束、寄完獎品後，記得刪除試算表裡的本名、手機欄位和雲端硬碟的「排行榜佐證照片」資料夾。

## 戰力分數公式

- 划船機：公尺 × 5
- 飛輪：公尺 × 2
- 650 分以上 B 獎區任選、800 分以上 A 獎區任選（登錄台會自動顯示）

倍數要調整時，`config.js` 的 `MULTIPLIER` 和 `Code.gs` 的 `MUL` 要一起改。
